경기도 여주시 흥천면 · GW-952LMA 가압펌프

지역
여주시 흥천면
장비
GW-952LMA 가압펌프 (1HP) · 압력스위치
증상
수압이 확연히 약해짐. 물을 잠가도 모터가 계속 돎
점검
압력스위치 교체 → 토출측 밸브 개폐 테스트 → 누수·부속·질소탱크 확인
원인
압력스위치 부식·노후 + 부동전 누수 + 질소탱크 압력 저하 + 내부 부속 마모
조치
압력스위치 교체·재조정, 누수·부속·탱크 상태 함께 점검
결과
교체 직후 정상 정지 확인, 남은 원인까지 함께 설명

현장 상황

여주 흥천면 주택에서 얼마 전부터 수압이 확연히 약해졌다는 연락을 받았습니다. 도착해 보니 GW-952LMA(1HP) 가압펌프가 물을 잠가도 계속 돌아가고 있었습니다.

사용 중인 GW-952LMA. 물을 잠가도 멈추지 않았습니다.

점검 순서

  1. 압력스위치 확인: 철분으로 많이 부식돼 있어 새 제품으로 교체했고, 바로 정상적으로 멈췄습니다.
  2. 토출측 바로 옆 밸브를 열어 재테스트: 모터가 다시 멈추지 않는 현상이 나타났습니다.
  3. 배관 확인: 앞마당 부동전(동파방지 수전)에서 물이 많이 새고 있었습니다.
  4. 내부 부속 마모와 질소탱크 압력 확인

철분으로 부식된 기존 압력스위치(오른쪽)와 새 압력스위치.

앞마당 부동전에서 새는 물. 이만큼 새면 압력이 계속 빠집니다.

원인

한 가지가 아니라 여러 원인이 겹쳐 있었습니다.

  • 압력스위치가 낡고 부식돼 압력을 제대로 감지하지 못했습니다.
  • 부동전 누수로 배관 압력이 계속 빠져나가 모터가 쉬지 못했습니다.
  • 질소탱크 충전 압력이 기준보다 낮아 펌프가 더 자주, 더 오래 돌아야 했습니다.
  • 철분이 다소 많은 지하수 때문에 내부 부속(임펠러·커버·씰 등)이 마모돼 압력이 예전보다 느리게 올라갔습니다.

조치와 결과

압력스위치를 교체하고 재조정했습니다. 한 번 방문했을 때 부동전 누수, 내부 부속 마모, 질소탱크 상태까지 함께 확인해 여러 원인을 같이 설명드렸습니다.

비슷한 증상이라면

  • 부동전이나 배관 연결부 주변에 물이 고이거나 젖어 있는지 보세요.
  • 수압이 서서히 약해졌는지, 갑자기 약해졌는지 시점을 기록해 두면 진단에 도움이 됩니다.
  • 압력탱크 표면에 녹이나 부푼 흔적이 있는지 확인하세요. 탱크 압력을 직접 조작하지는 마세요.

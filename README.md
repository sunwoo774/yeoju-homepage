# 여주 한일윌로모터펌프 - 파워펌프 서비스센터

여주시 지역 지하수 모터펌프, 배수펌프, 심정펌프, 압력탱크, 동파, 인버터 낙뢰 피해 출장수리 전문 웹사이트입니다.
가평/홍천/남양주/경기도광주와 색상·레이아웃·서비스 표현 방식을 전부 다르게 제작했습니다.

## 이 사이트만의 차별점

- **톤**: 버건디(wine) + 라이스골드(gold) + 따뜻한 아이보리 배경. "정직한 동네 수리센터" — 실용적인 아이콘 카드 기반 서비스업체 톤.
  (가평=네이비/골드·글래스, 홍천=딥그린/코랄·세리프, 남양주=차콜/오렌지·모노스페이스, 광주=코발트/테라코타·벤토그리드, 이천=모노크롬/레드·갤러리, 춘천=틸/피치·오가닉)
- **헤더**: 일반 서비스업체형 단일 바 헤더 (로고 + 메뉴 + 전화 버튼).
- **히어로**: 트러스트 카드(9년 경력·당일출장·직접방문·야간가능)를 아이콘과 함께 배치해 신뢰감을 먼저 전달.
- **서비스 표현**: 아이콘이 있는 카드 그리드 — 각 서비스마다 원형 아이콘 배지 + 제목 + 설명 + 세부 항목.
- **증상 안내**: 원형 경고 아이콘이 있는 체크리스트.
- **출장권역**: 매장 소재지(양평) 강조 없이 여주 자체 권역(여주읍·가남읍·흥천면 등)을 표(table) 형식으로 정직하게 안내.
- **참고**: 초기 버전은 신문 마스트헤드 + 한자 워터마크를 활용한 에디토리얼 매거진 스타일이었으나, "지하수 수리업체로 안 보인다"는 피드백을 반영해 아이콘 기반의 실용적인 서비스업체 톤으로 재조정했습니다.
